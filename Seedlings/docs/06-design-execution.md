# 06 — Design Execution

Решение D-14: макет и код — один артефакт. Промежуточного канваса нет, экраны сразу
собраны компонентами Next.js, правки идут в одном месте.

## Что реализовано

| Экран | Маршрут | Состав |
|---|---|---|
| Главная | `/` | Все 12 блоков карты страниц: первый экран, доверие, плитка культур, сезонная лента, хиты, преимущества, доставка, самовывоз, промо, отзывы, советы, FAQ, подписка |
| Каталог | `/catalog` | Фасеты, сортировка, чипсы, «показать ещё», перелинковка, SEO-текст, FAQ |
| Каталог культуры | `/catalog/[culture]` | То же + предопределённая культура, свой H1, лид и SEO-описание |
| Карточка | `/product/[slug]` | Галерея, бейджи, фасовки, покупка, доверие, характеристики, описание, уход, отзывы, допродажа, похожие |
| Корзина | `/cart` | Позиции, количества, промокод, расчёт доставки, порог бесплатной, допродажа |
| Чекаут | `/checkout` | Способ получения, контакты, оплата, промокод, сводка, валидация |
| Успех | `/checkout/success` | Номер заказа, памятка первого дня, состав, статус, ссылка на накладную |
| Накладная | `/invoice/[id]` | Печатная форма с артикулами и суммой прописью |
| Избранное | `/favorites` | Сетка, пустое состояние |
| Кабинет | `/account` | Заказы, повтор заказа, данные, подписки |
| Поиск | `/search` | Оверлей с автокомплитом + страница результатов на движке каталога |
| Акции | `/sale` | Промокоды с условиями и сроками, товары со скидкой |
| Доставка | `/delivery` | Упаковка, тарифная таблица, самовывоз, погодные ограничения |
| Оплата и гарантии | `/guarantee` | Способы оплаты, условия гарантии 14 дней |
| Советы | `/care` | Календарь работ по месяцам, разборы, уход по культурам |
| О питомнике | `/about` | История, как работаем, контакты |
| Подборка | `/collection/[slug]` | 4 подборки под задачу, состав с объяснением «зачем каждая позиция», покупка одной кнопкой |
| Сравнение | `/compare` | До 4 сортов, 13 характеристик, режим «только отличия», состав в адресе страницы |

| Служебные | `/404`, `/robots.txt`, `/sitemap.xml` | — |

Каталог — 54 сорта в 7 культурах, данные детерминированы (хэш слага), поэтому сборки воспроизводимы.

## Ключевые решения реализации

| ID | Решение | Почему |
|---|---|---|
| D-05 | Агрономические характеристики — типизированные поля | Один массив кормит фильтры, характеристики и сниппет карточки |
| D-06 | Несезонный товар остаётся в каталоге с формой подписки | SEO и сбор базы к сезону |
| D-08 | Состояние фильтров живёт в URL | Выдача шарится и индексируется |
| D-09 | Корзина, избранное и заказы — вне React, в localStorage | Переживают навигацию, синхронизируются между вкладками |
| D-13 | Изображения — параметрический SVG из модели товара | Фото нет; картинка не может разойтись с данными |
| D-14 | Этап 6 сразу в коде, без канваса | Одно место правок |
| D-15 | Индексация закрыта (`robots.ts`) | Цены, остатки и отзывы демонстрационные |
| D-16 | Фасовка — отдельный SKU (`slug--p9`) | Так же устроен учёт в Бизнес.ру: остаток считается по фасовке |
| D-17 | Оптимистичная отметка фасета хранится вместе со строкой запроса | Фильтр идёт через сервер; отметка обязана появиться сразу, но не пережить ответ |
| D-18 | Панели шапки хранятся вместе с маршрутом, на котором открыты | Навигация закрывает их сама, без setState в эффекте и каскада рендеров |
| D-19 | Расчёт доставки — таблица зон внутри сайта | У живых растений особые условия перевозки, общий калькулятор врёт |
| D-21 | Подборка задаётся предикатом, а не списком слагов | Состав пересобирается сам при смене ассортимента и не ломается, когда сорт уходит из продажи |
| D-22 | Полоса сравнения — на всю ширину внизу, а не кнопка в углу | В правом нижнем углу она перекрывает кнопку «В корзину» в последней карточке сетки |
| D-23 | Состав сравнения зашит в адрес страницы, правки меняют адрес | Сравнением делятся ссылкой; иначе кнопка «Очистить» у пришедшего по ссылке молча ничего не делает |
| D-24 | Микроразметка живёт в `components/structured-data.tsx` | Product, Offer, AggregateRating, Review, BreadcrumbList, FAQPage, Article, ItemList, GardenStore собираются из тех же данных, что и страница |

## Проверка в браузере

Установлен headless-Chromium, написаны два скрипта:

- `Seedlings/scripts/visual-check.mjs` — 21 маршрут × 2 брейкпоинта (390 и 1440):
  HTTP-статус, горизонтальный скролл, ошибки консоли, скриншоты.
- `Seedlings/scripts/flow-check.mjs` — 36 интерактивных сценариев: фасеты, чипсы, поиск,
  избранное, корзина, промокоды, валидация чекаута, самовывоз, оформление, накладная,
  кабинет, повтор заказа, подписка на несезонный товар, выбор фасовки, сравнение сортов,
  покупка подборки одной кнопкой, статьи и перелинковка, микроразметка, мобильные меню и шторка фильтров.

Запуск: `pnpm start:seedlings` в одном терминале, `pnpm check:seedlings` — в другом.

### Что нашла проверка и что исправлено

| Дефект | Исправление |
|---|---|
| Горизонтальный скролл 20–57 px на каталоге при 390 px: селект сортировки распирал строку тулбара | Тулбар переведён в grid, на мобильном селект занимает свою строку |
| Сплошной оверлей ссылки карточки перехватывал клики по сердцу избранного | Сердце и кнопка подняты на `z-20`, карточке добавлен `isolate` |
| Липкая шапка накрывала цель прокрутки | `scroll-padding-top: 6rem` на `html` |
| Иллюстрации в карточках дублировали название ссылки для скринридера | Появился режим `decorative` — в плитках и карточках SVG немой |
| Ягода клубники читалась как перец | Форма перерисована: круглая «щека» сверху, остриё снизу, чашелистик |
| `setState` в эффекте в трёх местах (каскадные рендеры) | Состояние привязано к ключу (маршрут / строка запроса), эффекты убраны |
| «Очистить сравнение» не работало у пришедшего по ссылке: состав перечитывался из адреса | Правки состава переписывают адрес страницы (D-23) |
| Кнопки в карточках одного ряда не выстраивались по нижней границе | Блок покупки прижат `mt-auto` |
| «Ремонтантная · ремонтантный» — подтип и срок дублировались в характеристике и в описании | Срок не выводится, когда подтип уже его назвал |
| «садовая клубники» — описание собиралось через родительный падеж | Формула изменена на «Клубника «Полка» — садовая»: подтип согласован с названием культуры |

`pnpm build:seedlings` и `pnpm lint:seedlings` проходят чисто.

## Что осталось непроверенным

Реальные устройства, Safari и мобильный Chrome, скринридер, контрастность в измерении,
производительность на медленной сети, печать накладной на бумагу.
