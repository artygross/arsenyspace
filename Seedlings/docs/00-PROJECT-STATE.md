## Зафиксированные решения

| ID | Решение | Обоснование |
|---|---|---|
| D-01 | Ниша — живой сезонный товар, это определяет архитектуру | Наличие трёхзначное, доверие — функция, а не украшение |
| D-02 | Модель B2C: питомник продаёт напрямую садоводу | Бриф. Убирает оптовые прайсы и B2B-логику |
| D-03 | Ассортиментное ядро — ягодные культуры + овощная и цветочная рассада | Название сообщества ВК; подтвердить у клиента |
| D-04 | Mobile-first | Трафик из ВК — почти целиком телефон |
| D-05 | Агрономические характеристики — типизированные поля, не текст | Кормят фильтры, характеристики и сниппеты одновременно |
| D-06 | Несезонный товар не скрывается: остаётся страница с подпиской | SEO и сбор email-базы к сезону |
| D-07 | Гостевой чекаут, аккаунт создаётся по email | Регистрация до оплаты убивает конверсию у аудитории 45+ |
| D-08 | Состояние фильтров — в URL | Шарящиеся и индексируемые выдачи |
| D-09 | Корзина, избранное, заказы — localStorage вне React | Переживают навигацию, синхронизируются между вкладками |
| D-10 | Цена показывается за упаковку + за штуку | Эконом-сегмент считает поштучно, продавать поштучно нерентабельно |
| D-11 | Отзывы — в первой волне | В нише живого товара отзыв дороже любого текста о качестве |
| D-12 | Сравнение сортов — во вторую волну | Фильтры и характеристики закрывают 80 % задачи дешевле |
| D-13 | Изображения — параметрический SVG из модели товара | Фотоконтента нет; картинка не может разойтись с данными |
| D-14 | Этап 6 — сразу компоненты Next.js, без канваса | Макет и код — один артефакт |
| D-15 | Индексация закрыта (`robots.ts`) | Цены, остатки и отзывы демонстрационные |
| D-16 | Фасовка — отдельный SKU (`slug--container`) | Так же устроен учёт в Бизнес.ру |
| D-17 | Оптимистичная отметка фасета привязана к строке запроса | Отклик за 100 мс без каскада рендеров |
| D-18 | Панели шапки привязаны к маршруту | Навигация закрывает их сама |
| D-19 | Доставка — тарифная таблица зон внутри сайта | У живых растений особые условия перевозки |
| D-20 | Сайт рассады — отдельное приложение `Seedlings/site` на ветке `seedlings` | Решение пользователя: рассада отдельно от магазина очков, очки сохраняются нетронутыми |
| D-21 | Подборка задаётся предикатом отбора, а не списком слагов | Состав пересобирается при смене ассортимента, подборка не ломается при уходе сорта |
| D-22 | Полоса сравнения — во всю ширину внизу | Кнопка в правом нижнем углу перекрывает «В корзину» в последней карточке |
| D-23 | Состав сравнения зашит в адрес, правки переписывают адрес | Сравнением делятся ссылкой; иначе «Очистить» у получателя ссылки не срабатывает |
| D-24 | Микроразметка собирается из тех же данных, что и страница | Разметка не может разойтись с содержимым карточки |
| D-25 | Название — **Полесье**, без кавычек; в реквизитах и накладной — КФХ Полесье | Подтверждено клиентом. Рабочее «Своя грядка» снято |
| D-26 | Данные из ВК берём официальным API, а не разбором страниц | Страницы закрыты антибот-проверкой; обходить её нельзя, а API отдаёт товары, цены и фото легально |
| D-27 | Бейдж Netlify отключён на проекте | Его плавающая плашка 194×64 в правом нижнем углу перехватывала клики по полосе сравнения, на мобильном — на половине ширины экрана |
| D-28 | Эмблема живёт в двух видах: полная и знак без кольца | Кольцевая надпись ниже 40 px превращается в шум, а в интерфейсе знак ровно такого размера |
| D-29 | Производные логотипа собираются скриптом, а не правятся руками | Клиент пришлёт вектор или новую версию — пересборка одной командой, размеры и обрезка не разъезжаются |

## Что сделано после CP-03

Эмблема клиента подключена. Исходник — `assets/logo-source.png`; `scripts/logo-prep.mjs` снимает
белый фон, обрезает поля и вырезает знак без кольца, из него же собираются фавиконка и иконка iOS.
В шапке и футере стоит знак без кольца, полная эмблема — на «О питомнике» и в шапке накладной
(D-28). Подпись рядом со знаком повторяет название, поэтому для скринридера знак декоративен.

Заодно из проверки сценариев убраны оставшиеся гонки: избранное, кабинет, повтор заказа,
очистка корзины, пересчёт цены по фасовке и «только отличия» ждали таймера, а не факта.
Таймеров-заглушек в скрипте не осталось; под полной нагрузкой машины (сборка в соседнем
процессе) прогон всё ещё может упереться в 30-секундный таймаут навигации — это среда,
а не дефект: проверка рассчитана на свободный сервер, `pnpm start:seedlings` + `pnpm check:seedlings`.

## Ожидает материалов клиента

- **Фотографии товаров.** Приёмный слой готов: файл `public/photos/<слаг>.jpg` → `node Seedlings/scripts/photo-manifest.mjs` → фото появляется в каталоге, карточке, корзине и сравнении. Пока файлов нет, работает параметрическая иллюстрация (D-13).
- **Данные из сообщества ВК.** Страницы ВК закрыты антибот-проверкой, автоматический разбор HTML невозможен. Написан импорт через официальный API — `scripts/vk-import.mjs`, нужен токен приложения или сообщества. Он забирает название, описание, товары с ценами, посты и фотографии, складывает сырьё в `Seedlings/vk-export/` и качает снимки в `public/photos/vk/`.
- **Домен.** Название подтверждено (Полесье), домен и почта пока заглушки `polesie.example`.
- **Вектор логотипа.** Растр получен и подключён; вектор нужен только под полиграфию.
