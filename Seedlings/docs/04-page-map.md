## Блоки главной (`/`)

1. **Первый экран** — H1, подзаголовок, две кнопки (в каталог / что сажать сейчас), сезонный статус отгрузки, четыре маркера доверия строкой.
2. **Плитка культур** — 7 тайлов с числом сортов. Главный навигационный блок.
3. **Сезонная лента** — «Что сажать в <месяц>»: 4–8 карточек товара.
4. **Хиты сезона** — товарная карусель/сетка с бейджами «Хит», «−20 %».
5. **Почему нам доверяют** — 4 пункта: свой питомник, гарантия 14 дней, упаковка, отгрузка в срок.
6. **Как мы доставляем** — три шага + сроки, ссылка на `/delivery`.
7. **Самовывоз** — адрес, часы, карта-заглушка, «0 ₽ и можно посмотреть растение».
8. **Акции и промокод** — баннер с активным промокодом сезона.
9. **Отзывы покупателей** — 3 карточки с фото урожая, ссылка на все.
10. **Советы** — 3 материала из `/care`.
11. **FAQ** — 6 вопросов, аккордеон (микроразметка `FAQPage`).
12. **CTA + подписка** — «Сообщим, когда откроется отгрузка», поле email.

## Блоки каталога (`/catalog`, `/catalog/[culture]`)

Хлебные крошки → H1 + короткое описание культуры (SEO, 2–3 строки, не «портянка») →
строка управления (число товаров, сортировка, кнопка «Фильтры» на mobile) →
активные фильтры чипсами со сбросом → сетка карточек (2 кол. mobile / 3 tablet / 4 desktop) →
пагинация «показать ещё» → блок перелинковки по культурам → SEO-текст и FAQ внизу.

**Карточка товара в сетке:** изображение растения, бейджи (скидка / хит / новинка / предзаказ),
культура + название сорта, ключевая характеристика строкой («Ремонтантная, −30 °C»),
фасовка («5 шт. в кассете»), цена + старая цена + цена за штуку, статус отгрузки,
кнопка «В корзину», иконка избранного. Ничего лишнего — карточка читается за секунду.

## Блоки карточки товара (`/product/[slug]`)

- Хлебные крошки
- Галерея (изображение сорта; на первой версии — параметрическая иллюстрация)
- Заголовок: культура + сорт, рейтинг, артикул
- Бейджи и статус наличия с датой отгрузки
- Выбор фасовки (кассета / P9 / горшок) — меняет цену и артикул
- Цена, цена за штуку, экономия
- Кнопка «В корзину» + избранное, при `preorder` — «Оформить предзаказ», при `out_of_season` — «Сообщить о поступлении»
- Мини-блок доверия: доставка от, самовывоз 0 ₽, гарантия 14 дней
- Таблица характеристик сорта (срок, зимостойкость, урожайность, размер ягоды, высота, свет, окно посадки)
- Описание сорта — живым языком
- «Посадка и уход» — 4 шага
- Отзывы: рейтинг, распределение, форма добавления
- «С этим сортом берут» — допродажа комплектом
- «Похожие сорта»
