# 05 — UI System

Фирменного стиля у клиента нет — система предложена с нуля. Ограничение брифа: тёмные цвета не использовать.

## 1. Палитра

| Токен | HEX | Роль |
|---|---|---|
| `ink` | `#1c2b21` | Основной текст. Глубокий зелёно-графитовый вместо чёрного — мягче и «живее» |
| `ink-muted` | `#5d6f63` | Вторичный текст, подписи |
| `surface` | `#ffffff` | Карточки, шапка, поля форм |
| `cream` | `#fbf8f1` | Фон страницы. Молочный, не белый — снимает офисную стерильность |
| `sand` | `#f2e9d7` | Тёплый бежевый: секции, баннеры, блок самовывоза |
| `line` | `#e4ded0` | Границы, разделители |
| `leaf` | `#2f7a4a` | Главный зелёный: кнопки, ссылки, активные состояния |
| `leaf-deep` | `#235c38` | Hover/pressed основной кнопки |
| `leaf-soft` | `#e8f2e6` | Заливка вторичных элементов, чипсы, фон иконок |
| `grass` | `#8cc63f` | Травяной акцент: декор, иллюстрации, прогресс. Не для текста |
| `berry` | `#c8452f` | Скидки, распродажа, ошибки |
| `sun` | `#e0982a` | Предзаказ, акции, рейтинг |

Правила: чёрного нет нигде; серый только как `ink-muted`; на цветной плашке текст либо белый,
либо `ink` — промежуточных вариантов нет. Контраст основного текста к `cream` — 12:1,
белого текста к `leaf` — 5:1, оба выше AA.

## 2. Типографика

- **Заголовки** — Manrope 700/600. Геометрический гротеск с мягкими окончаниями: современный, но не холодный.
- **Текст** — Inter 400/500. Максимальная читаемость с телефона для аудитории 45+.
- Шкала: H1 32/40 mobile → 48/56 desktop; H2 24 → 34; H3 20 → 22; body 16 (**минимум 16 px — не уменьшать**); small 14; caption 12.
- Длина строки — до 68 символов. Межстрочный в тексте — 1.6.

## 3. Сетка и ритм

- Контейнер max 1280, поля 16 mobile / 32 tablet / 48 desktop.
- Колонки: 12 desktop, 6 tablet, 4 mobile. Сетка товаров 2 / 3 / 4.
- Шаг спейсинга — 4 px. Вертикальный ритм секций: 48 mobile / 88 desktop.
- Брейкпоинты: 480 / 768 / 1024 / 1280.

## 4. Скругления, тени, границы

- Радиусы: карточка 20, кнопка 999 (pill), поле 14, чипс 999, баннер 28.
- Тень одна: `0 4px 16px rgba(28,43,33,.06)`, на hover карточки — `0 10px 28px rgba(28,43,33,.10)`.
- Граница `1px solid line` — базовый способ разделения; тень добавляется только к интерактивным карточкам.

## 5. Кнопки

| Вариант | Вид | Где |
|---|---|---|
| Primary | Заливка `leaf`, белый текст, pill | «В корзину», «Оформить заказ» |
| Secondary | Белая, граница `leaf`, текст `leaf` | «Подробнее», «В избранное» |
| Soft | Заливка `leaf-soft`, текст `leaf-deep` | Второстепенные действия в карточке |
| Ghost | Только текст с подчёркиванием при hover | Ссылки-действия, «Сбросить фильтры» |
| Danger | Текст `berry` | «Удалить из корзины» |

Состояния обязательны все: rest / hover / active / focus-visible (кольцо 2 px `leaf` с отступом 2) /
disabled (40 % прозрачности) / loading (спиннер, ширина не прыгает) / success («Добавлено ✓» на 1.5 с).
Высоты: L 52, M 44, S 36. На mobile тап-таргет не меньше 44 px.

## 6. Карточка товара

Белая, радиус 20, граница `line`. Сверху — изображение на подложке `leaf-soft` c соотношением 4:5,
бейджи в левом верхнем углу (максимум два), сердце избранного — в правом.
Ниже: культура капслоком `ink-muted` 12 → название сорта 16/500 → характеристика строкой →
фасовка → цена (18/700) + старая цена + «₽/шт.» → статус отгрузки → кнопка на всю ширину.
Hover: подъём на 2 px и усиление тени. Вся карточка кликабельна, кнопка и сердце — свои цели.

## 7. Бейджи

Приоритет показа: скидка > предзаказ > хит > новинка, максимум два.
`sale` — заливка `berry`/белый; `preorder` — заливка `sun`/белый; `hit` — `leaf-soft`/`leaf-deep`;
`new` — белый с границей `leaf`; `out` — `sand`/`ink-muted`. Все pill, 11 px, uppercase, letter-spacing .06em.

## 8. Баннерная система

Три типоразмера, одна логика: подложка `sand` или `leaf-soft`, иллюстрация растения справа,
текст слева, одна кнопка. Никаких фото-подложек с текстом поверх — на mobile это всегда нечитаемо.

- **Hero** (главная) — 2 колонки desktop / стек mobile, декоративная иллюстрация, высота не фиксируется.
- **Промо-полоса** — одна строка: заголовок + промокод в пунктирной рамке + кнопка.
- **Сезонный тайл** — квадратный, внутри сетки товаров каждые 8 карточек.

## 9. Иконки и декор

Линейные, 1.5 px, скруглённые концы, размер 20/24, наследуют `currentColor` — свой набор в `icons.tsx`,
без иконочных библиотек. Декор: волна-«грядка» между секциями, силуэты листьев в углах баннеров,
пунктирная рамка у промокода. Декор всегда `aria-hidden`.

## 10. Фотостиль (когда появятся съёмки)

Дневной свет, естественный фон (грунт, теплица, руки садовода), без тяжёлых теней и без коллажей.
Три обязательных кадра на сорт: растение целиком в фасовке, корневая система крупно, урожай (ягода/плод).
Кадр «корневая система» — главный аргумент доверия и обязателен.
**До появления фото** изображения товаров — параметрические SVG-иллюстрации, генерируемые из модели товара
(культура + цвет плода): картинка не может разойтись с данными, а каталог не выглядит пустым (решение D-13).

## 11. Логотип

Название — **Полесье**, без кавычек. В реквизитах, футере и накладной — КФХ Полесье.

У клиента есть собственный логотип: круглая эмблема с лейкой, клубникой, малиной и аистом,
надпись по кольцу. Подстановка — поле `COMPANY.logo` в `lib/content.ts`, компоненты не трогаются.

Что учесть: эмблема круглая и мелкодетальная. В шапке она работает на 32–40 px, ниже 24 px
надпись по кольцу нечитаема — для favicon и мелких размеров нужна упрощённая версия знака
(например, только ягоды и лейка без кольца). Голубой и красный с эмблемы в палитру интерфейса
не переносятся: эмблема остаётся акцентом на зелёно-молочном фоне.

Временный знак — круглая «лунка» и два семядольных листа, шрифтовая часть Manrope 700 —
рисуется, пока `COMPANY.logo` пуст, и остаётся запасным вариантом.

## 12. Правила поведения интерфейса

1. Любое действие даёт отклик за 100 мс — оптимистичное состояние, не ожидание сервера.
2. Добавление в корзину не уводит со страницы: кнопка меняется на «Добавлено ✓», счётчик в шапке анимируется.
3. Ошибка формы — под полем, красным `berry`, с конкретным текстом; фокус переводится на первое ошибочное поле.
4. Пустые состояния всегда с действием («В избранном пусто → Перейти в каталог»).
5. Скелетоны вместо спиннеров в сетках товаров.
6. Фокус виден всегда, `:focus-visible` не отключается.
7. Модалка на mobile — шторка снизу, закрывается свайпом и по Esc, фон блокируется от скролла.
8. Цена и статус наличия никогда не показываются без даты отгрузки.
