# 01 — Interview (сбор требований)

Регламент `Seedlings/claud.md` §2 требует интервью до начала проектирования.
Первый источник ответов — бриф `Seedlings/seedlings.md`; пункты, которых в нём не было,
помечались как **допущение**. 27 августа 2026 клиент прислал описание питомника, условия
доставки, оплаты и возврата — дословно они лежат в `13-client-source.md`, и часть допущений
заменена фактами. Что из-за этого меняется на сайте — `14-brief-diff.md`.

## Бизнес

| Вопрос | Ответ |
|---|---|
| Что за магазин | Питомник саженцев «Полесье»: малина, клубника, голубика, смородина, ежевика |
| Категория товаров | Живые растения — скоропортящийся, сезонный, «страшный» для онлайн-покупки товар |
| Модель продаж | B2C / D2C. Производитель-питомник продаёт напрямую конечному садоводу |
| Текущий формат | Офлайн + продажи через сообщество ВК `vk.ru/kupit_sazhentsy_maliny_klubniki` |
| Модель сделки (**подтверждено** 27.08.2026) | Бронь без предоплаты на сезон, оплата по факту получения в пункте выдачи |
| Ключевая цель | Продажи (оформленный заказ), не заявки и не подписки |
| Ценовой сегмент | Эконом и средний |
| Объём каталога | 34 сорта в семи разделах — `12-assortment.md` |
| Ассортиментное ядро (**подтверждено** 27 августа 2026) | Малина ремонтантная и летняя, смородина ЗКС, клубника ЗКС и фриго, ежевика, голубика. Полный список — `docs/12-assortment.md` |

## Пользователи

| Вопрос | Ответ |
|---|---|
| Кто покупает | Частный садовод-любитель, дача/участок, 35–65 лет, женщин заметно больше |
| Поведение | Не быстрая покупка. Выбор с изучением: сорт, срок созревания, зимостойкость, «приживётся ли» |
| Второй сегмент | Возвратный покупатель из ВК — уже знает продавца, ему нужна скорость и корзина, а не убеждение |
| Устройства | Мобильный приоритет. Трафик из ВК — почти целиком телефон |
| География (**подтверждено** 27.08.2026) | Питомник — Ленинградская обл., Ломоносовский р-н, д. Воронкино. Отправка по России, отдельные условия для Санкт-Петербурга и Кронштадта |

## Каталог

| Вопрос | Ответ |
|---|---|
| Сколько товаров | 50–500 |
| Нужны ли фильтры | Да, по брифу |
| Вариации | Да — фасовка/возраст саженца: кассета, горшок P9, ЗКС, ОКС, количество в упаковке |
| Особенность ниши | Сезонность. Товар физически существует не круглый год → нужны статусы «в наличии», «предзаказ», «сезон закрыт» |

## UX и референсы

| Вопрос | Ответ |
|---|---|
| Референсы | `garshinka.ru`, `agromarket.ru` |
| Что берём | Плотный товарный каталог, крупные фото растения, понятные характеристики сорта, акцент на сезонных подборках |
| Что не берём | Перегруженность, «оптовый» вид прайса, тёмные и кричащие акции |
| Запрет по визуалу | Тёмные цвета не использовать |
| Тон | Природный, свежий, живой, современный, дружелюбный, вызывающий доверие |

## Технические ограничения

| Вопрос | Ответ |
|---|---|
| Платформа | Next.js (App Router) в этом репозитории, ветка `seedlings` |
| Приоритет | Mobile-first, desktop равноценен по качеству, но проектируется вторым |
| Обязательные функции | Каталог, карточка, корзина, чекаут, ЛК, избранное, фильтры, поиск, акции, промокоды, автонакладная, авторасчёт доставки |
| Обязательные интеграции | Email-уведомления, самовывоз, Бизнес.ру |
| Явно вне объёма | МойСклад, 1С, Telegram-бот, CRM |
| Условно | СДЭК Pay — только при подтверждении; всё сомнительное помечается опциональным |
