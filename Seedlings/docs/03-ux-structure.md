# 03 — UX Structure

## 1. Как пользователь попадает на сайт

| Канал | Доля (прогноз) | Точка входа | Что должен увидеть первым |
|---|---|---|---|
| ВК-сообщество, пост о сорте | высокая | Карточка товара | Цену, наличие, срок отгрузки, кнопку в корзину — без прелюдий |
| Поиск «купить саженцы малины <город>» | высокая | Каталог категории | Ассортимент и цены, а не длинный SEO-текст |
| Поиск «сорт Полка описание» | средняя | Карточка сорта | Характеристики + «купить» рядом |
| Прямой заход / повтор | средняя | Главная | Сезонный статус: что сейчас отгружается |

Вывод: **каждая страница — посадочная.** Карточка товара обязана самостоятельно закрывать
доверие (доставка, гарантия, отзывы), не рассчитывая, что человек прочитал главную.

## 2. Как быстро понять ассортимент

Три уровня входа, в порядке убывания частоты:

1. **Плитка культур на главной** — «Клубника, Малина, Смородина, Жимолость, Крыжовник,
   Овощная рассада, Цветы». Крупные тайлы с картинкой и числом сортов. Это главный навигационный элемент.
2. **Сезонная лента** — «Что сажать в августе»: подборка, привязанная к текущему месяцу.
   Снимает вопрос «а сейчас-то что покупать».
3. **Поиск** — для тех, кто знает название сорта. Автокомплит по сорту и культуре.

## 3. Как выбирается товар

**Каталог.** Фасеты (левая колонка на desktop, шторка снизу на mobile):

- Культура — главный фасет, всегда сверху
- Тип (ремонтантная / садовая / штамбовая…) — зависит от культуры
- Срок созревания — ранний / средний / поздний / ремонтантный
- Наличие — в наличии / предзаказ (по умолчанию **в наличии** включён)
- Зимостойкость — до −20 / −25 / −30 и ниже
- Фасовка — кассета / P9 / горшок 1 л / ОКС
- Цена — диапазон
- Только со скидкой

Правила: состояние фильтров пишется в URL (шарится и индексируется); фасет, дающий 0 товаров,
не скрывается, а показывается неактивным с числом 0 — иначе человек не понимает, почему пункт исчез.
Сортировка: по популярности (умолчание), цене ↑↓, новизне, сроку созревания.

**Карточка товара** отвечает на пять вопросов в этом порядке:
что это → сколько стоит и что в упаковке → когда отгрузят → приживётся ли у меня (зимостойкость,
регион, уход) → что говорят другие (отзывы).

## 4. Как оформляется заказ

Корзина → чекаут одной страницей (без шагов-визарда), три блока:

1. **Способ получения** — переключатель «Доставка / Самовывоз». Выбор мгновенно пересчитывает
   итог и меняет набор полей. Самовывоз показывает адрес, часы и дату готовности.
2. **Контакты** — имя, телефон, email. Email обязателен: на него уходят подтверждение и накладная.
3. **Оплата** — при получении / онлайн (опционально, см. `08-integrations.md`).

Сквозной блок справа (снизу на mobile): состав заказа, поле промокода, расчёт доставки, итог.
Промокод применяется без перезагрузки, ошибка показывается тут же.

Правила чекаута:
- никакой обязательной регистрации;
- поля с автозаполнением и правильными `inputmode` — аудитория заполняет с телефона;
- кнопка «Оформить заказ» дизейблится только по факту невалидной формы, с подсветкой конкретного поля;
- после оформления — экран успеха с номером заказа, накладной (печать/PDF) и памяткой «что делать с растением в первый день».

## 5. Как сайт снижает страх покупки растений онлайн

Страх у этой аудитории конкретный, и на каждый нужен отдельный элемент интерфейса:

| Страх | Ответ в интерфейсе | Где |
|---|---|---|
| «Придёт засохшим» | Блок «Как мы упаковываем»: корневая в торфяном коме, влагоудерживающий гель, срок в пути | Карточка, доставка, чекаут |
| «Не приживётся» | Гарантия замены 14 дней при фото-подтверждении | Карточка, футер, чекаут |
| «Не переживёт мою зиму» | Явное поле «Зимостойкость до −30 °C» + фильтр | Каталог, карточка |
| «Пересорт, вырастет не то» | Отзывы с фото урожая, паспорт сорта, происхождение маточника | Карточка |
| «Когда сажать, я не агроном» | Блок «Посадка и уход» — 4 шага, и «Окно посадки: апрель–май» | Карточка, раздел «Советы» |
| «Кому я плачу» | Реквизиты, адрес питомника, самовывоз, телефон, ссылка на ВК с историей | Футер, о нас, чекаут |

## 6. Навигация

- **Шапка (mobile):** логотип, поиск, избранное, корзина, кнопка «Каталог» → полноэкранное меню культур.
- **Шапка (desktop):** логотип, «Каталог» с выпадающим списком культур, «Доставка», «Оплата и гарантии», «Советы», поиск, избранное, корзина.
- **Липкая полоса** с сезонным статусом («Отгрузка весенней партии — с 15 апреля. Предзаказ открыт») — одна строка, закрывается.
- **Футер:** культуры, помощь, контакты и адрес самовывоза, ВК, реквизиты, оферта.
- Хлебные крошки на всех страницах каталога и карточки — они же микроразметка `BreadcrumbList`.

## 7. Обязательный состав e-commerce (§6 регламента)

| Требование | Есть | Где |
|---|---|---|
| Home | ✅ | `/` |
| Category / Collection | ✅ | `/catalog`, `/catalog/[culture]`, подборки `/collection/[slug]` |
| Product page | ✅ | `/product/[slug]` |
| Cart | ✅ | `/cart` |
| Checkout | ✅ | `/checkout` + `/checkout/success` |
| Account | ✅ | `/account` (по email, без пароля на первой версии) |
| Search | ✅ | оверлей + `/search` |
| Filters | ✅ | фасеты в URL |

Отклонений от обязательного состава нет.
