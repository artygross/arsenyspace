# Своя грядка — интернет-магазин рассады

Проект живёт на ветке `seedlings`. Магазин солнцезащитных очков в корне репозитория не тронут:
он остаётся на `main` и запускается своими командами.

```bash
pnpm dev:seedlings     # http://localhost:3210
pnpm build:seedlings
pnpm lint:seedlings
pnpm start:seedlings   # и в другом терминале:
pnpm check:seedlings   # вёрстка (18 маршрутов × 2 брейкпоинта) + 26 сценариев в браузере
```

| Папка | Что внутри |
|---|---|
| `seedlings.md` | Бриф клиента |
| `claud.md` | Регламент процесса |
| `docs/` | Документация этапов: интервью, анализ, UX, карта страниц, UI-система, реализация, передача, интеграции, вопросы клиенту, тексты |
| `site/` | Приложение Next.js 16 (App Router, Tailwind 4) |
| `scripts/` | Проверка вёрстки и сценариев в headless-браузере |

Начать чтение: [docs/00-PROJECT-STATE.md](docs/00-PROJECT-STATE.md).

Данные каталога демонстрационные — цены, остатки и отзывы вымышлены, индексация закрыта
(`site/app/robots.ts`). Снимается одной строкой при боевом запуске.
