## Приоритет проектирования
Экраны разбиваются на три волны — макеты делаются в этом порядке:

- **Волна 1 (ядро сделки):** Главная · Каталог · PDP · Корзина · Чекаут
- **Волна 2 (дифференциаторы):** Квиз подбора · Сравнение · Отзывы · Поиск
- **Волна 3 (обвязка):** Бренды · Аккаунт · Помощь · Пустые состояния

Каждый экран волны 1 делается в двух брейкпоинтах (mobile 390 / desktop 1440) — приоритет устройств равный.
