# 01 — Interview (сбор требований)

Статус: **закрыт**
Источник задачи: `Test/test.md` — «создай интернет магазин очков»

## Бизнес
| Параметр | Значение |
|---|---|
| Тип | Интернет-магазин солнцезащитных очков |
| Модель продаж | B2C, мультибренд-ритейлер |
| Ключевая цель | Продажи (transactional) |
| Ассортимент | Только солнцезащитные очки. Оптика с диоптриями **вне объёма** |

## Пользователи
| Параметр | Значение |
|---|---|
| География | Россия |
| Язык / валюта | Русский / ₽ |
| Поведение | Смешанное: выбор и сравнение (премиальный чек) + импульсная покупка в сезон |

## Каталог
| Параметр | Значение |
|---|---|
| Объём | 300—1000 моделей |
| Фильтры | Обязательны, фасетные |
| Вариации | Цвет оправы × цвет линзы × размер оправы |

## UX
| Параметр | Значение |
|---|---|
| Визуальный тон | Премиальный fashion: контрастная палитра, крупный тип, имиджевые съёмки, акцент на бренды |
| Фичи в объёме | Подбор по форме лица · Сравнение моделей · Отзывы и рейтинги |
| Фичи вне объёма | Виртуальная примерка (AR) |

## Технические ограничения
| Параметр | Значение |
|---|---|
| Платформа | Next.js, текущий репозиторий |
| Приоритет устройств | Равный (mobile + desktop прорабатываются параллельно) |

## Открытые вопросы (не блокируют проектирование)
1. Способы оплаты и доставки (СДЭК / Почта / курьер / ПВЗ) — влияет на шаги чекаута.
2. Есть ли офлайн-точки — влияет на самовывоз и блок «где примерить».
3. Наличие программы лояльности — влияет на состав Account.
4. Источник 3D/фото контента: имиджевые съёмки vs packshot на белом — влияет на карточку товара.
