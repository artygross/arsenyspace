# 05 — UI System (базовые компоненты и правила)

Тон: **премиальный fashion**. Принцип — интерфейс молчит, говорит товар. Хром сдержанный, контраст создаётся типографикой и крупным фото, а не цветом.

## Токены

**Палитра**
| Роль | Значение | Применение |
|---|---|---|
| Ink | `#111111` | Текст, кнопки, шапка |
| Ink muted | `#6B6B6B` | Вторичный текст, спеки |
| Surface | `#FFFFFF` | Фон карточек, PDP |
| Surface alt | `#F4F2EF` | Секции главной, подложка галереи |
| Line | `#E4E1DC` | Разделители, границы полей |
| Accent | `#8A6A3D` | Только акценты: активный фасет, фокус |
| Sale | `#B3261E` | Только цена со скидкой и бейдж Sale |
| Success | `#2E6B4F` | Наличие, подтверждение |

Цвет не несёт смысла в одиночку — состояние всегда дублируется формой или подписью.

**Типографика.** Дисплейная антиква для заголовков и названий брендов; нейтральный гротеск для UI и спек. Шкала: 56 / 40 / 28 / 20 / 16 / 14 / 12. Межстрочный 1.2 для заголовков, 1.5 для текста.

**Сетка.** Desktop 12 колонок, максимум 1440, поля 64, желоб 24. Tablet 8 колонок. Mobile 4 колонки, поля 16.
Каталог: 4 карточки в ряд на desktop, 3 на tablet, 2 на mobile.

**Spacing.** Шаг 4: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96. Вертикальный ритм секций — 96 desktop / 56 mobile.

**Радиусы и тени.** Радиус 0—2 (премиальный тон не терпит скруглений). Теней нет; глубина — через границу `Line` и фон `Surface alt`.

## Компоненты (обязательный набор, регламент §7)

### Карточка товара
Состояния: обычная · hover (смена на фото «на модели») · нет в наличии · со скидкой.
Состав: фото 4:5 · бренд (акцентный вес) · модель · цена (со старой ценой при скидке) · свотчи доступных цветов · рейтинг со счётчиком · иконка избранного · чекбокс сравнения.
Правило: не больше 6 свотчей, дальше `+N`. Карточка кликабельна целиком, свотчи меняют фото без перехода.

### Фильтры
Типы контролов: слайдер цены · чекбокс-список с поиском · свотчи цвета · иконки формы оправы · сегменты размера.
Обязательно: счётчик у каждого значения, дизейбл нулевых, чипы выбранного, «Сбросить всё», липкая кнопка «Показать N моделей» на mobile.

### Навигация
Шапка (обычная / липкая сжатая) · мега-меню · мобильный оверлей с аккордеонами · хлебные крошки · футер.

### Кнопки / CTA
Primary (заливка Ink) · Secondary (граница) · Ghost · Icon. Размеры L 52 / M 44 / S 36. Состояния: default · hover · active · focus (кольцо Accent) · disabled · loading. Главный CTA на PDP — липкий на mobile.

### Модальные окна
Размерная таблица оправ · галерея отзывов · быстрый просмотр из каталога · подтверждение удаления из корзины · панель фильтров на mobile (полноэкранная).

### Формы
Поле · селект · чекбокс · радио · переключатель · textarea · загрузка фото отзыва.
Правила: лейбл всегда сверху и всегда виден, плейсхолдер не заменяет лейбл. Ошибка — под полем, текстом, с иконкой. Валидация по blur, не по каждому нажатию. Автоформат телефона и индекса.

### Бейджи
Sale (−30%) · Новинка · Хит · Последняя пара · Эксклюзив. Не более двух на карточке, приоритет: Sale > Последняя пара > Новинка.

### Дополнительные (специфика товара)
- **Спецификация размеров оправы** — визуальная схема `52□18-145` со ссылкой «как измерить свои».
- **Свотч линзы** — двойной кружок: цвет оправы + цвет линзы.
- **Блок доверия** — оригинал · возврат 14 дней · официальный дилер. Один компонент, переиспользуется на PDP, в корзине и в чекауте.
- **Рейтинг** — звёзды + число + счётчик отзывов, кликабелен к отзывам.
- **Панель сравнения** — плавающая, с миниатюрами и счётчиком.

## Правила поведения интерфейса
1. Любое действие даёт отклик за 100 мс; загрузка выдачи — скелетоны, не спиннер.
2. Добавление в корзину не уводит со страницы: тост + обновление счётчика; переход в корзину — по явному действию.
3. Фильтр применяется без перезагрузки, URL обновляется, кнопка «назад» браузера возвращает предыдущий набор фасетов.
4. Фокус видим всегда, порядок табуляции соответствует визуальному, модалки ловят фокус.
5. Изображения товара — фиксированное соотношение 4:5, без сдвига макета при загрузке.
6. Все цены — с валютой и разрядами: `24 900 ₽`.
