# 03 — UX Structure (структура магазина)

## Информационная архитектура

```
Главная
├── Каталог
│   ├── Женщинам
│   ├── Мужчинам
│   ├── Унисекс
│   └── По форме оправы (авиаторы, вайфареры, кошачий глаз, круглые, ...)
├── Бренды
│   └── Страница бренда → его каталог
├── Новинки
├── Sale
├── Подбор  ← квиз по форме лица
└── Помощь
    ├── Доставка и оплата
    ├── Возврат и обмен
    ├── Гарантия оригинальности
    └── Как выбрать размер оправы
```

Служебные, вне основной навигации: Поиск · Корзина · Избранное · Сравнение · Аккаунт · Чекаут.

## Навигация

**Desktop.** Липкая шапка: логотип → основные разделы → поиск (раскрывающийся) → избранное · сравнение · корзина · аккаунт.
Наведение на «Каталог» и «Бренды» раскрывает мега-меню: колонки категорий + промо-изображение в правой трети.

**Mobile.** Шапка: бургер · логотип · поиск · корзина. Нижняя панель не используется — она конфликтует с премиальным тоном и съедает высоту у крупных фото. Навигация — полноэкранный оверлей с аккордеонами.

## Система фильтров

Порядок фасетов задан анализом (цена и бренд — первые):

1. Цена (слайдер + ввод)
2. Бренд (поиск внутри списка, при 300+ моделях брендов десятки)
3. Форма оправы (иконки-пиктограммы, не текст)
4. Форма лица — «подойдут мне» (связка с квизом)
5. Цвет оправы (свотчи)
6. Цвет линзы (свотчи)
7. Тип линзы (поляризация, зеркальная, градиент, фотохром)
8. Материал
9. Размер оправы (S/M/L + подсказка «как измерить»)
10. Пол
11. Наличие

**Поведение:**
- Desktop — левая колонка, липкая, всегда развёрнута. Mobile — кнопка «Фильтры» → полноэкранная панель, применение по кнопке, счётчик найденного в шапке панели.
- Выбранные фасеты — чипами над выдачей, с «Сбросить всё».
- Каждое значение показывает количество товаров; нулевые значения дизейблятся, а не скрываются.
- Состояние фильтров пишется в URL — выдача шарится и индексируется.
- Пустая выдача — не тупик: показывает, какой фасет снять, и предлагает ближайшие модели.

## Сравнение
Чекбокс на карточке товара (появляется на hover / всегда виден на mobile) → плавающая панель внизу с миниатюрами → страница сравнения. Лимит 4 модели. Строки сравнения: фото, бренд, цена, форма, размеры, материал, тип линзы, UV, рейтинг. Различия подсвечиваются, совпадающие строки можно свернуть.

## Подбор по форме лица
Квиз 4 шага: форма лица (с иллюстрациями) → предпочитаемый стиль → размер (по подсказке) → бюджет. Результат — не список из 3 моделей, а **предфильтрованный каталог** с объяснением «почему это вам подходит». Прогресс сохраняется, шаг назад не теряет ответы. Результат квиза сохраняется в аккаунт/localStorage и становится фильтром «Мне подойдут» в каталоге.

## Поиск
Оверлей с автокомплитом: бренды · модели · категории · популярные запросы. При пустом вводе — недавние запросы и топ-бренды. Полная страница результатов использует ту же систему фильтров, что и каталог.
