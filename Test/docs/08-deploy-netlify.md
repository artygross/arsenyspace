# 08 — Выкладка на Netlify

Пошаговая инструкция. Всё делается в браузере, ничего устанавливать не нужно.
Репозиторий уже готов: https://github.com/artygross/arsenyspace

---

## Шаг 1. Завести аккаунт

1. Открыть **https://app.netlify.com/signup**
2. Нажать **Sign up with GitHub** — так Netlify сразу получит доступ к репозиториям, и отдельная авторизация не понадобится.
3. GitHub спросит подтверждение — нажать **Authorize Netlify**.

Netlify бесплатен для такого проекта: лимитов бесплатного тарифа хватает с большим запасом.

---

## Шаг 2. Создать проект из репозитория

1. В панели Netlify нажать **Add new project** (кнопка справа сверху) → **Import an existing project**.
2. В списке провайдеров выбрать **GitHub**.
3. Netlify попросит установить своё приложение в GitHub. Появится экран **Install Netlify**:
   - выбрать **Only select repositories**,
   - в списке отметить **arsenyspace**,
   - нажать **Install**.

   Так Netlify получит доступ только к этому репозиторию, а не ко всем сразу.
4. Вернувшись в Netlify, выбрать репозиторий **artygross/arsenyspace** из списка.

---

## Шаг 3. Проверить настройки сборки

Откроется экран с настройками. Netlify определит Next.js сам и подставит значения из `netlify.toml`. Нужно только убедиться, что стоит:

| Поле | Значение |
|---|---|
| **Branch to deploy** | `main` |
| **Build command** | `pnpm build` |
| **Publish directory** | оставить как есть — Netlify подставит сам |

Переменные окружения не нужны: проект самодостаточен, внешних API и ключей нет.

Нажать **Deploy arsenyspace**.

---

## Шаг 4. Дождаться сборки

Откроется страница деплоя с логом. Сборка занимает **3—6 минут** при первом запуске.

В логе последовательно пройдут стадии: установка зависимостей через pnpm, `pnpm build`, затем работа адаптера Netlify. В конце должно появиться зелёное **Published**.

Если что-то пошло не так — см. раздел «Если сборка упала» ниже.

---

## Шаг 5. Открыть сайт

Адрес будет вида `https://случайное-имя-12345.netlify.app` — он показан вверху страницы проекта.

**Чтобы сделать адрес человеческим:**
1. **Project configuration** → **General** → **Project details**
2. **Change site name**
3. Ввести, например, `optika-store` → адрес станет `https://optika-store.netlify.app`

---

## Шаг 6. Проверить, что всё работает

Пройти по живому сайту:

- [ ] Главная открывается, шрифты подгрузились (заголовок набран антиквой, не системным шрифтом)
- [ ] `/catalog` — отметить любой бренд в фильтре: выдача пересчиталась, адрес в строке браузера изменился
- [ ] Кнопка «назад» в браузере вернула прежнюю выдачу
- [ ] `/product/lume-orbita` — «В корзину», счётчик в шапке стал `1`
- [ ] Обновить страницу — корзина не опустела
- [ ] `Ctrl+K` — открылся поиск, ввод «ави» показал подсказки
- [ ] `/robots.txt` — отдаёт `Disallow: /`
- [ ] Открыть сайт с телефона — меню-бургер, панель фильтров, таблица сравнения прокручивается вбок внутри себя

Первый заход на динамическую страницу (`/catalog`, `/search`, `/compare`, страница бренда) может быть на секунду медленнее — это «холодный старт» серверной функции. Дальше быстро.

---

## Дальше всё обновляется само

Каждый `git push` в ветку `main` запускает новую сборку и публикацию. Ничего нажимать не нужно.

Ветки и пул-реквесты получают собственные превью-адреса — можно показать изменение, не трогая основной сайт.

---

## Если сборка упала

Лог открывается по клику на неудачный деплой: **Deploys** → выбрать красный → **Deploy log**.

| Что видно в логе | Причина и что делать |
|---|---|
| Ошибка на `pnpm install`, жалоба на версию pnpm | В `package.json` указано `packageManager: pnpm@11.8.0`. Netlify ставит эту версию через corepack. Если ругается — убрать поле `packageManager` и пересобрать |
| `fetch failed` рядом с упоминанием fonts.googleapis.com | Сборка скачивает шрифты Inter и Playfair Display. Обычно это временный сбой — нажать **Retry deploy** |
| Жалоба на версию Node | В `netlify.toml` закреплена 22. Поменять `NODE_VERSION` на `20` или `24`, закоммитить, запушить |
| Сборка проходит, но страницы отдают 404 | Проверить, что в настройках проекта не прописан вручную publish directory — он должен определяться автоматически |

Локально сборка воспроизводится командой `pnpm build` — если она проходит у вас, а на Netlify нет, дело в окружении, и ответ будет в логе.

## Когда сайт поднимется

Проверки из `scripts/` можно прогнать по живому адресу:

```bash
BASE_URL=https://ваш-адрес.netlify.app node scripts/visual-check.mjs
BASE_URL=https://ваш-адрес.netlify.app node scripts/flow-check.mjs
```

Это покажет, ведёт ли себя приложение на серверных функциях Netlify так же, как локально.
