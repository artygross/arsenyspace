# 02 — Analysis (разбор бизнес-логики)

## Главный барьер покупки
Очки нельзя примерить онлайн. Всё продуктовое ядро строится вокруг снятия одного вопроса: **«подойдут ли они мне?»**

Три выбранные фичи — не украшения, а три ответа на этот вопрос:

| Фича | Какое сомнение снимает | Где живёт |
|---|---|---|
| Подбор по форме лица | «Какая форма мне идёт» | Отдельная точка входа + переиспользуется как фильтр |
| Сравнение моделей | «Какие из трёх выбрать» | Каталог → плавающая панель → страница сравнения |
| Отзывы с фото | «Как это выглядит на живом человеке» | PDP, ключевой блок |

**Вывод для UX:** размеры оправы и форма лица — не второстепенные спеки, а первоклассные атрибуты. Они выносятся в фильтры, в карточку товара и в верхнюю часть PDP.

## Второй барьер: доверие мультибренда
Премиальные бренды подделывают. Ритейлер без собственного имени обязан доказывать подлинность.
→ Сквозной модуль доверия: гарантия оригинальности, официальный дилер, условия возврата — видимы на PDP и в чекауте, не спрятаны в футере.

## Сезонность
Солнцезащитные очки — выраженный сезонный товар (пик март—август).
→ Главная страница должна быть **перестраиваемой витриной** (слоты под коллекции/дропы/сезон), а не статичной вёрсткой. Это требование к компонентам, а не к контенту.

## Ценовой разброс
В премиальном мультибренде разброс 8 000—80 000 ₽ в одном каталоге.
→ Фильтр по цене и по бренду — первые два фасета, всегда видимы.

## Модель данных товара
Определяет фильтры, карточку и PDP. Фиксируется здесь как единый источник правды:

- **Идентичность:** бренд, модель, коллекция, артикул
- **Форма оправы:** авиатор · вайфарер · кошачий глаз · круглые · прямоугольные · овальные · спортивные · oversize
- **Материал:** ацетат · металл · титан · комбинированный
- **Цвета:** цвет оправы, цвет линзы (независимые вариации)
- **Линза:** поляризация · зеркальная · градиент · фотохром; UV-защита; категория светопропускания 0—4
- **Размеры:** ширина линзы □ переносица — заушник (напр. `52□18-145`), сводный размер S / M / L
- **Аудитория:** женские · мужские · унисекс
- **Рекомендация:** подходящие формы лица (овал, круг, квадрат, сердце, вытянутое) — вычисляемый атрибут, связывает квиз с каталогом
- **Коммерция:** цена, скидка, наличие, срок доставки

## Ключевые пользовательские сценарии
1. **Знаю бренд** → поиск/бренд-страница → PDP → корзина. Должен занимать ≤3 экрана.
2. **Знаю примерно, что хочу** → каталог → фильтры (форма, цена) → сравнение 2—3 → PDP.
3. **Не знаю ничего** → квиз подбора → предфильтрованная выдача → PDP.
4. **Вернулся** → избранное / история заказов → повтор.

Сценарий 3 — главный дифференциатор, ему выделяется постоянная точка входа в навигации и слот на главной.
